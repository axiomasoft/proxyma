# Сообщение об уязвимости

Сообщите о уязвимости приватно владельцам репозитория
<https://github.com/axiomasoft/proxyma>. Если у репозитория включены private
vulnerability reports, используйте их. Не открывайте public issue с секретами,
учётными данными, дампами трафика или деталями эксплуатирующего запроса.
Публичный issue допустим только после исправления и без этих данных.

## Граница доверия

Authorizer по умолчанию запрещает операции: пакет не выдаёт разрешение из-за
отсутствия политики. Секреты хранятся в зашифрованном виде; проверка TLS не
отключается (`verifyPeer=false` и `verifyHost=false` невозможны). Состояние
`unknown_after_authorization` не доказывает, что байты не были отправлены.
Устройство этой границы — [docs/security.md](docs/security.md).
